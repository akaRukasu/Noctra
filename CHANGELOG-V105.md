# Noctra Media Client — Changelog V105

## Objectif
Corriger la régression de responsive desktop introduite par la généralisation du mode workspace sur les sous-menus lourds.

## Corrections principales
- Téléchargements, Médiathèques, Automatisation et Demandes ne passent plus automatiquement en workspace immersif sur PC.
- Le mode workspace desktop est conservé pour À découvrir et l’Explorateur média, là où il reste pertinent.
- Les panneaux desktop concernés retrouvent un format large dédié, plus naturel sur écran PC.
- Ajustement des largeurs et paddings desktop pour les panneaux larges.
- Densité améliorée pour les listes Téléchargements et les grilles d’Automatisation.
- Cartes Médiathèques rééquilibrées pour un rendu plus cohérent sur PC.

## Impact attendu
- Menus desktop moins “mobile / plein écran forcé”.
- Meilleure lisibilité sur grand écran.
- Dock et panneaux mieux proportionnés côté PC.

## Sécurité
Édition Server Safe, sans ajout de binaire Windows ni runtime externe.
