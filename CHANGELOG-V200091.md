# Noctra 200.0.91

DaddyLive et DLStreams utilisent le cadrage vidéo au lieu du mode page web complète. Les iframes vidéo déclarent `scrolling="no"`; le conteneur n'ajoute plus de défilement. Les pages de secours complètes conservent leur navigation.

Cette modification ne supprime pas les publicités internes des fournisseurs externes et ne réactive pas les restrictions sandbox rejetées par certains lecteurs. Les réglages du serveur, dont le retrait de BowdTV, sont conservés par l'updater.
