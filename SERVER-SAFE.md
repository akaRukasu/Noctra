# Noctra v139 — archive Server Safe

Cette archive est destinée au déploiement serveur/Ultra.cc. Elle contient Noctra Web + Node v139 et exclut volontairement les lanceurs et scripts Windows qui pouvaient déclencher des détections heuristiques antivirus.

Sont exclus de cette archive :

- `.exe`
- `.dll`
- `.vbs`
- `.bat`
- `.cmd`
- `.ps1`
- client Desktop/Tauri et mécanismes d’autostart Windows

La suppression de ces composants n’enlève aucune fonction du serveur Noctra, de la PWA, de la TV, du Multiview, de Discovery, Jellyseerr, Prowlarr ou des outils d’administration web.
