# Noctra Windows 0.5.9

Le connecteur WiTV spécifique au client Windows a été supprimé. Le client demande au serveur Noctra le catalogue et les options de lecture TV. Les sources fournies comme accès manuels restent sélectionnables dans la fiche et ne sont pas lancées automatiquement.

Le test Windows a affiché trois sources distinctes renvoyées par l’API de test. Il a aussi vérifié les filtres de pays et la lecture HLS de 360p à 1080p. Les tests de protocole et de regroupement TV ont réussi. Le menu TV fixe de la 0.5.8 reste en place.

Installer cette version après la mise à jour du serveur Noctra 200.0.174 pour obtenir le détail des sources WiTV.
